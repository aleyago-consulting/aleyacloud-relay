# Fichas de producción por proyecto

Esta carpeta contiene una ficha inicial por cada proyecto reservado en AleyaCloud.
Mueve o copia cada una al repositorio correspondiente, por ejemplo como
`docs/PRODUCCION.md`, y mantenla junto a la configuración de entrega.

No almacenes aquí contraseñas, tokens, claves ni certificados. De cada secreto se
documentan solamente el nombre y su finalidad; los valores van como archivos en
`/srv/secrets/<proyecto>/production/`.

| Proyecto | Ficha |
| --- | --- |
| goClinicals | `goclinicals/PRODUCCION.md` |
| Aleya Homes | `aleyahomes/PRODUCCION.md` |
| Club Trainers | `clubtrainers/PRODUCCION.md` |
| Aleya Suite | `aleyasuite/PRODUCCION.md` |
